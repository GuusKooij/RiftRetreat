# RiftRetreat v1.0.0

**First official release!** 🎉

## 📥 Download

Download `RiftRetreat-v1.0.0-windows.zip` from the Assets section below, extract it, and run `RiftRetreat.exe`.

**No API key required!** - RiftRetreat includes a shared production API key so you can start using it immediately.

## ✨ Features

### Performance Analytics
- **Comprehensive Stats**: Track KDA, CS/min, vision score, kill participation, damage, and more
- **Win Condition Analysis**: Discover which stats correlate most with your wins
- **Role Performance**: Compare performance across all 5 roles
- **Time-of-Day Analysis**: Find your best and worst times to play
- **Tilt Detection**: Monitor losing streaks and session performance drop-off

### Champion Insights
- **Champion Pool Analysis**: See your best and worst performing champions
- **Smart Recommendations**: Data-driven suggestions on which champions to play or avoid
- **Mastery Tracking**: Track progress toward mastery milestones
- **Per-Champion Stats**: Detailed breakdowns for every champion

### Challenge Tracking
- **300+ Challenges**: Track progress on all League challenges
- **Smart Recommendations**: Get champion suggestions that progress multiple challenges simultaneously
- **Mastery Milestones**: See which champions are close to mastery level-ups

### Duo Partner Analysis
- **Recurring Teammates**: See who you play with most
- **Win Rate by Partner**: Track performance with each duo partner
- **Champion Pool Visibility**: View top 5 champions played by each partner (with icons!)

### Ranked Climb Tracking
- **LP History**: Track your LP over time
- **Promotion Predictor**: Estimate games needed to reach promos
- **Session Summaries**: Review net LP and performance per gaming session

### Additional Features
- **Win Rate Calendar**: Visual heatmap of daily performance
- **Advanced Stats**: First blood rate, comeback victories, gold efficiency, damage analysis
- **Vision Analysis**: Track control wards, vision score by role
- **Match History**: Complete match history with filters
- **Dark Theme**: League-style dark UI with gold accents

## 🚀 Getting Started

1. **Download** the ZIP file from Assets below
2. **Extract** to a folder of your choice
3. **Run** `RiftRetreat.exe`
4. Enter your **Riot ID** (e.g., `YourName#EUW`)
5. Select your **region**
6. Click **"Fetch Data"**

The initial data fetch may take 2-5 minutes depending on your match history size.

## 🐛 Known Issues

- **Rate Limiting**: Large match history fetches may take several minutes due to API rate limits
- **Windows Only**: Currently only available for Windows (Mac/Linux support planned)

## 📊 System Requirements

- Windows 10/11 (64-bit)
- ~120 MB disk space
- Active League of Legends account
